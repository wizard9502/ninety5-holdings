# Ninety5 Holdings

Official website for **Ninety5 Holdings** — the parent company of:

- **Ninety5 Ventures** — Financial inclusion & technology. First incubated project: [Bouteek](https://bouteek.shop)
- **Ninety5 Capital** — Investment arm (stocks & crypto)
- **Ninety5 Properties** — Real estate investment & management

## Tech stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Deployed on Vercel

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Structure

- `/` — Holdings landing page
- `/ventures` — Ninety5 Ventures
- `/capital` — Ninety5 Capital
- `/properties` — Ninety5 Properties
